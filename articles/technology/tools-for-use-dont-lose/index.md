A personal index and curated collection of essential web applications, media downloaders, creative assets, AI playgrounds, and digital utilities. This list serves as a reliable reference for small but high-utility tools kept for quick access.

---

## 🎨 Image & Vector Utilities

### 1. [SVGcode](https://svgco.de/)
* **URL:** [https://svgco.de/](https://svgco.de/)
* **Category:** Raster-to-Vector Converter / WebAssembly PWA
* **Overview:** A Progressive Web App (PWA) that converts raster images (PNG, JPG, WebP, GIF) into clean SVG vector graphics directly inside your browser using `potrace-wasm`.
* **Why it's useful:** It runs entirely client-side, meaning no images are ever sent to an external server. It supports fine-tuning thresholding, smoothing, and color optimization.

### 2. [EZGIF](https://ezgif.com/)
* **URL:** [https://ezgif.com/](https://ezgif.com/)
* **Category:** Animated GIF & Media Editing Suite
* **Overview:** A web-based toolset for creating, editing, cropping, resizing, reversing, optimizing, and converting animated GIFs, WebP, APNG, and video formats.
* **Why it's useful:** A dependable Swiss Army knife for quick GIF manipulations and file compression without installing heavy desktop editing software.

## 📥 Media & Video Downloaders

### 3. [cobalt](https://cobalt.tools/)
* **URL:** [https://cobalt.tools/](https://cobalt.tools/)
* **Category:** Open-Source Media Downloader
* **Overview:** An ad-free, privacy-respecting media downloader application that saves video, audio, and clips from major platforms without trackers, popups, or paywalls.
* **Why it's useful:** It supports YouTube, Twitter/X, TikTok, Instagram, Reddit, SoundCloud, and Bluesky with options for audio extraction, quality selection, and clean file naming.

### 4. [Twitter Video Downloader](https://twittervideodownloader.com/)
* **URL:** [https://twittervideodownloader.com/](https://twittervideodownloader.com/)
* **Category:** Social Media Video Utility
* **Overview:** A dedicated web tool for extracting and downloading MP4 videos and animated GIFs directly from Twitter/X post URLs.
* **Why it's useful:** Provides a simple, lightweight backup option when you need to quickly save media from tweets across different video resolutions.
